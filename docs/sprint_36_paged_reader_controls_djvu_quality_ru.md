# Sprint 36 — postраничное чтение, управление, DJVU HiDPI и macOS universal engine

## Цели

1. Улучшить постраничный режим PDF/DJVU.
2. Убрать текстовые подсказки и всплывающие сообщения из нижней шкалы.
3. Добавить desktop-клавиши курсора.
4. Вернуть компактные прозрачные кнопки перелистывания на Android без конфликта с FAB-кнопками.
5. Улучшить качество рендера DJVU на Android.
6. Исправить вероятную причину пустых DJVU-страниц на Intel macOS: embedded dylib теперь собирается universal `x86_64 + arm64`.

## Изменения

### DJVU

- Обновлён render profile: `paged-hidpi-v3`, чтобы старые размытые/пустые кэши пересоздались.
- Рендер DJVU теперь выполняется с дополнительным oversampling поверх физического DPR:
  - Android: до 3600 px по ширине и 5400 px по высоте;
  - desktop: до 3200 px по ширине и 4600 px по высоте.
- macOS native engine теперь собирается как universal dylib:
  - `x86_64-apple-darwin`;
  - `aarch64-apple-darwin`;
  - объединение через `lipo`.

### Постраничный reader

- PDF и DJVU поддерживают листание свайпом влево/вправо.
- На desktop добавлены клавиши:
  - `←` / `→` — предыдущая/следующая страница;
  - `↑` / `↓` — прокрутка текущей страницы вверх/вниз.
- При переходе вперёд страница открывается сверху.
- При переходе назад предыдущая страница открывается снизу.

### Нижняя шкала быстрого перехода

- Убраны текстовые подсказки и SnackBar.
- На desktop шкала активируется наведением мыши.
- На телефонах первый тап активирует шкалу, после чего можно вести по шкале для быстрого перехода.
- Активная шкала становится толще и меняет цвет:
  - прочитанная часть — индиго;
  - непрочитанная часть — приглушённый индиго.
- В неактивном состоянии остаётся золотой прогресс.

### Android

- Возвращены компактные прозрачные кнопки перелистывания поверх текста.
- Кнопки находятся по центру левого/правого края и не конфликтуют с кнопками полноэкранного режима/закладок.

## Relay

Relay обновлять не нужно. Серверная часть не менялась.

## Проверки

### GitHub Actions

- Flutter tests/analyze должны пройти.
- Android native DJVU engine должен собраться и попасть в APK.
- macOS package step должен показать universal dylib через `file`.

### Ручная проверка

1. macOS Intel: открыть DJVU и убедиться, что страницы больше не пустые.
2. Android: открыть DJVU и проверить чёткость текста.
3. PDF/DJVU: свайпы влево/вправо листают страницы.
4. macOS/Linux/Windows: стрелки `←`/`→` листают страницы, `↑`/`↓` прокручивают текущую страницу.
5. Desktop: шкала увеличивается при наведении и позволяет быстро перейти по книге.
6. Android: первый тап активирует шкалу, затем можно вести по ней.
7. Android: прозрачные кнопки перелистывания не перекрывают кнопки полноэкранного режима.
