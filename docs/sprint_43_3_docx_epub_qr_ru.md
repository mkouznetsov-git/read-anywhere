# Sprint 43.3 — DOCX polish, EPUB jump alignment, QR scanner rollback

## DOCX

- Исправлен сброс сквозной многоуровневой нумерации после заголовков верхнего уровня: generated top-level numbering теперь обновляет текущий верхний номер для подпунктов.
- Префикс нумерации заголовка теперь наследует стиль заголовка, а не рисуется обычным текстом.
- Убран видимый эффект «лесенки» для юридических абзацев, где номер уже находится в тексте: Flutter не умеет Word tab stops/first-line indent один-в-один, поэтому для таких абзацев сохраняется единая левая кромка.
- Таблицы стали ближе к Word:
  - сохранены переносы строк внутри ячеек по абзацам Word;
  - заголовочная строка центрируется;
  - короткие ячейки в компактных таблицах центрируются;
  - первая колонка компактных таблиц выделяется жирным;
  - роли/служебные строки получают более близкое выделение.

## EPUB

- Обложка в reader-е теперь рендерится по ширине области чтения.
- Внутренний переход по ссылке теперь позиционирует реальный viewport по тому же проценту, который вычисляет locator/progress bar. Это закрывает ситуацию, когда ссылка показывала правильные 82.6%, но экран фактически оставался на 80.3%.

## QR scanner

- Экран сканирования QR возвращён на прежнюю controller-based реализацию `MobileScannerController`, которая раньше стабильно запускала камеру на Android.
- Сохранён короткий заголовок `Сканировать QR`.

## Ручная проверка

1. DOCX: проверить пункт 3 и подпункты 3.1/3.2, таблицы, отступы слева.
2. EPUB: в приложенной книге перейти по ссылке `Глава 16. Огранка, полировка, разработка`; viewport должен оказаться в зоне 82.6%, без последующего отскока на 80.3%.
3. EPUB: убедиться, что обложка занимает ширину страницы чтения и не дублируется.
4. Android: нажать `Сканировать QR`; камера должна открыться прежним способом.
