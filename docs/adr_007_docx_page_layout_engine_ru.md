# ADR 007 — DOCX page-layout engine

## Решение

DOCX в ReadArc должен отображаться как листовая модель документа, а не как адаптивный ebook-текст.

## Причина

DOCX — это формат фиксированной офисной вёрстки. Если рендерить его как обычный `Column` с `Text.rich`, зависящий от ширины экрана, один и тот же документ получает разную вёрстку на desktop и mobile. Для договоров, спецификаций, таблиц и подписей это неприемлемо.

## Принцип

- Парсер извлекает размер страницы, поля, стили, таблицы и page breaks из OOXML.
- UI рендерит документ на фиксированном логическом листе.
- Узкие экраны масштабируют весь лист, а не пересобирают строки.
- Текст остаётся выделяемым и копируемым, потому что рендеринг остаётся Flutter-based, а не bitmap-only.

## Последствия

- DOCX становится ближе к системным viewers.
- Мобильная версия перестаёт ломать переносы.
- Следующие улучшения можно делать поверх этой модели: полноценный colspan/rowspan, автоматическая пагинация по высоте, более точные tab stops, секции и advanced numbering.
