# Sprint 5 Hotfix 01 — clean archive without `.git`

В предыдущем Sprint 5 архиве случайно оказалась служебная папка `.git` с `HEAD`, указывающим на `master`. Это могло сбить GitHub Desktop: он начинал воспринимать распакованную папку как отдельный локальный репозиторий, а не как обновление существующего `readarc`.

Исправление:

- `.git` полностью удалён из архива;
- `__pycache__` удалён из архива;
- в архиве оставлены только проектные файлы: `.github`, `apps`, `docs`, `scripts`, `server`, `README_RU.md`, `docker-compose.yml`.

Правильный способ применения обновлений:

1. Склонировать существующий репозиторий `mkouznetsov-git/readarc` в отдельную рабочую папку.
2. Распаковать этот архив.
3. Скопировать содержимое папки `ra_sprint5` поверх рабочей папки репозитория.
4. Не удалять и не заменять родную папку `.git` в рабочей папке.
5. Сделать commit и push.
