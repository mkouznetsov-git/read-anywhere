# Sprint 12 — стабильный FB2 reader, копирование и fullscreen для всех текущих форматов

## Что исправлено

### Стабильный прогресс FB2

FB2-reader больше не вычисляет прогресс через RenderBox/видимые виджеты. Такой подход давал случайные скачки процентов при прокрутке, потому что высота блоков и порядок измерения могли отличаться между кадрами.

Теперь FB2 разбирается в детерминированные render-units:

- текстовые строки фиксированной высоты;
- заголовочные строки фиксированной высоты;
- изображения фиксированной высоты.

Locator сохраняется как `fb2-unit-anchor-v1`:

```json
{
  "type": "fb2-unit-anchor-v1",
  "unitIndex": 120,
  "unitCount": 2400,
  "progressPercent": 5.0
}
```

Это повторяет стабильную схему TXT-reader: точка чтения — первый логический unit у верхней границы viewport.

### Проценты внутри книги и в библиотеке

FB2-reader теперь сохраняет ровно тот же progressPercent, который показывает нижний progress bar. После закрытия книги список библиотеки должен показывать тот же процент, без прыжка.

## Что добавлено

### Выделение и копирование

- TXT: текст можно выделять через общий SelectionArea.
- FB2: текстовые строки доступны для выделения через SelectionArea.
- FB2 images: у изображения есть кнопка копирования; изображение копируется в clipboard как `data:image/*;base64,...`.

Нативное копирование бинарного изображения в clipboard зависит от платформы и будет отдельным production-улучшением.

### Переход по ссылкам

FB2-ссылки с внешними схемами (`http`, `https`, `mailto` и т.п.) открываются через default browser/application. Внутренние ссылки вида `#note1` пока показываются как внутренняя ссылка; навигация по ним будет отдельной задачей.

### Fullscreen для всех текущих форматов

Полноэкранный режим теперь есть для:

- TXT;
- FB2;
- PDF.

Для будущих форматов следует подключать такой же reader shell: скрываем app bar/progress bar и оставляем только контент, scrollbar и минимальные floating actions.

## Проверка

1. Открыть FB2.
2. Прокручивать вверх/вниз и проверить, что progress bar не прыгает назад-вперёд случайно.
3. Закрыть FB2 и проверить процент в библиотеке.
4. Открыть FB2 снова и проверить восстановление позиции.
5. Проверить sync позиции FB2 между Mac и Android.
6. Выделить и скопировать текст TXT/FB2.
7. Нажать внешнюю ссылку в FB2 — должен открыться браузер.
8. Нажать кнопку копирования у FB2-изображения.
9. Проверить fullscreen в TXT, FB2 и PDF.
