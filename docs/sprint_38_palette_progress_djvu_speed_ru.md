# Sprint 38 — палитра интерфейса, прогресс-бары и ускорение DJVU

## Что изменено

1. Возвращена палитра ReadArc в библиотечные карточки и элементы reader-а:
   - deep indigo;
   - warm gold;
   - paper background;
   - ink-blue text.

2. Карточка книги на странице библиотеки оставлена в двухстрочной логике:
   - первая строка — название книги;
   - вторая строка — формат, размер, прогресс, действие и меню.

   Формат и размер теперь отображаются менее броско: маленьким приглушённым текстом, без ярких чипов.

3. Полосы быстрого перехода:
   - визуально тонкая золотая полоса осталась тонкой;
   - область попадания пальцем на Android/iOS стала шире;
   - активная индиго-полоса стала примерно в 2 раза толще золотой;
   - всплывающие и нижние текстовые подсказки не используются.

4. Android-кнопки листания:
   - возвращены вниз;
   - сделаны компактными, полупрозрачными и в палитре ReadArc.

5. PDF/DJVU UI:
   - технические кнопки про текстовый слой убраны из PDF/DJVU reader-а;
   - для документов с извлечённым текстом добавлен пользовательский путь через long-press по странице: открывается выделяемый текст без термина «текстовый слой».

6. DJVU performance:
   - добавлена новая версия cache profile `paged-hidpi-v5-native-fast`, чтобы старые кэши пересоздавались;
   - добавлена предзагрузка соседних страниц;
   - добавлена передача PNG из native engine напрямую, без тяжёлого RGBA→PNG кодирования на Dart-стороне;
   - добавлено чтение геометрии страниц через embedded engine, чтобы не рендерить все страницы в фиксированном портретном соотношении.

## Relay

Relay не менялся. Обновлять сервер через SSH/GitHub Actions не нужно.

## Проверки

После заливки в GitHub проверить:

```bash
cd apps/flutter_client
flutter test
flutter analyze
```

В GitHub Actions также проверить, что native DJVU engine собирается для Android и macOS.

## Ручная проверка

1. Открыть библиотеку и проверить, что карточки снова выглядят в палитре ReadArc.
2. Открыть DJVU на Mac и Android.
3. Проверить, что листание DJVU стало быстрее после первой подготовки страницы.
4. Проверить, что соседняя страница открывается быстрее после предзагрузки.
5. Проверить Android-кнопки листания: компактные, снизу, в палитре.
6. Проверить полосы быстрого перехода:
   - mobile: попадание пальцем стало проще, сама золотая полоса осталась тонкой;
   - desktop: hover активирует более толстую индиго-полосу.
