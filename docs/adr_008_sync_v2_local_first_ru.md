# ADR 008 — Local-first синхронизация ReadArc

## Решение

UI библиотеки строится из локального manifest/store. Remote snapshot не является источником истины, который может безусловно заменить локальное состояние.

## Правила

- Remote snapshot merge может добавлять/обновлять книги и прогресс.
- Отсутствие книги в remote snapshot не означает удаление.
- Удаление — только через явный tombstone.
- Пустой или явно destructive snapshot не может перезаписать непустую локальную библиотеку.
- Health relay означает только живой HTTP endpoint, но не завершённую синхронизацию.
- Периодический sync не должен постоянно запрашивать snapshots; это снижает риск применения старой offline metadata.

## Причина

На тестовых сборках наблюдались случаи, когда после reconnect/чтения/добавления книг библиотека становилась пустой при статусе `Подключено`. Это опаснее, чем временно не принять remote snapshot, поэтому guard предпочитает сохранность локальных данных.
