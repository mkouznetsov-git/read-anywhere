# Sprint 22 — CHM/DJVU adapters, DOCX rich view, PDF cache, Sync UI cleanup

## Что изменено

### CHM
- Убран показ CHM как сырого текста.
- Добавлен нативный adapter-путь для desktop-сборок: ReadArc пытается распаковать CHM через `extract_chmLib`, `7z`/`7zz` или `unar`.
- После распаковки приложение собирает HTML/HHС/HHK главы, заголовки, параграфы, списки и изображения в единый документ для чтения.
- Если нативных инструментов нет или CHM сжат/повреждён, показывается понятное сообщение вместо бинарных кракозябр.

### DJVU
- Убран показ DJVU как сырого текста.
- Добавлен adapter-путь для DjVuLibre: сначала `djvutxt`/`djvused` для текстового слоя, затем `ddjvu` для рендера страниц в PNG.
- Если DjVuLibre недоступен на устройстве, ReadArc показывает аккуратное сообщение и продолжает хранить/синхронизировать оригинальный файл.

### DOCX
- DOCX теперь открывается отдельным rich-reader экраном, а не как плоский построчный текст.
- Абзацы отображаются с естественным переносом, заголовки крупнее, списки, таблицы и изображения идут отдельными блоками.
- Сохраняется базовое форматирование runs: bold, italic, underline.
- Добавлено копирование текста DOCX и закладки.

### PDF
- Сохранён режим fit-width.
- Снижена максимальная плотность рендера до разумной для скорости.
- Добавлен кэш отрендеренных PDF-страниц, чтобы при скролле/перерисовке страницы не рендерились заново.
- Увеличен cacheExtent списка страниц для более плавной прокрутки.

### Иконка и стиль
- Иконка обновлена: рисунок увеличен ближе к краям, фон стал немного светлее, палитра сохранена.
- Палитра интерфейса слегка осветлена в той же ReadArc-теме.

### Страница «Синхронизация»
- Убраны технические строки «Отправлено событий» и «Получено событий» из основного статуса.
- Убран пункт «Локальная разработка» из пользовательского выбора.
- Убраны кнопки «Проверить relay», «Подключиться», «Отключиться», «Отправить snapshot», «Запросить snapshot».
- `accountId` переименован в «Аккаунт».
- `device` переименован в «Название устройства».
- `deviceId` перенесён в основной статус как «Идентификатор устройства».
- «Relay endpoint» переименован в «Соединение».
- «Доверенные устройства» и «Дополнительно» стали раскрываемыми блоками.

## Важно

CHM и DJVU теперь имеют adapter-архитектуру, но на Android/iOS для полноценного просмотра всё ещё понадобится встроенный native layer/библиотеки. В desktop-сборках просмотр заработает при наличии системных инструментов:

- CHM: `extract_chmLib`, `7z`/`7zz` или `unar`.
- DJVU: `djvutxt`, `djvused`, `ddjvu` из DjVuLibre.

Следующий шаг для мобильных платформ — добавить настоящие Android/iOS native bindings или bundled binaries для CHM/DjVuLibre/MuPDF-подобного рендера.
