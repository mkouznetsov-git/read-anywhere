# Sprint 37 — Reader UI, progress scrub, DJVU quality

## Что изменено

1. Убраны пользовательские упоминания «текстового слоя» из PDF/DJVU UI.
   - Для PDF оставлена команда «Скопировать текст PDF».
   - Для DJVU оставлена команда «Скопировать текст DJVU», но extraction будет подключаться через embedded engine отдельно.
   - Пользователь не должен видеть технический термин «текстовый слой».

2. Полоса быстрого перехода добавлена для непостраничных reader-ов.
   - TXT использует тот же двухрежимный scrub-механизм, что и постраничный reader.
   - FB2/EPUB/DOC/DOCX также используют активируемую нижнюю шкалу.
   - Desktop: шкала активируется наведением мыши.
   - Mobile: первый тап активирует расширенную hit-zone, далее drag перемещает позицию.
   - Убраны всплывающие и нижние текстовые подсказки.

3. Android page-turn controls.
   - Кнопки перелистывания возвращены вниз.
   - Они компактные, полупрозрачные и выполнены в общем indigo-стиле.
   - Вспомогательные fullscreen-кнопки подняты выше, чтобы не наезжать на правую кнопку перелистывания.

4. Library list compact redesign.
   - Верхняя виртуальная строка: название книги на всю ширину.
   - Нижняя виртуальная строка: формат, размер, прогресс, «Читать/Скачать», меню.
   - Меню переименовано: «Удалить с устройства» и «Удалить из библиотеки».

5. DJVU quality/cache.
   - Render profile bumped to `paged-hidpi-v4`, чтобы старые страницы пересоздавались.
   - Android render target повышен до 4200×6200.
   - Desktop render target повышен до 3600×5200.
   - PNG encoding level снижен для ускорения записи кэша без потери качества изображения.

## Relay

Relay не менялся. Обновлять сервер через SSH/GitHub Actions не нужно.

## Проверки

```bash
cd apps/flutter_client
flutter pub get
flutter test
flutter analyze
```

## Ручная проверка

1. Открыть PDF/DJVU на Android: кнопки перелистывания должны быть снизу и не перекрывать fullscreen/bookmark/copy.
2. Открыть TXT/FB2/EPUB/DOCX: нижняя шкала должна активироваться как в постраничном режиме.
3. На desktop навести мышь на нижнюю шкалу: шкала должна расширяться и позволять быстрый переход.
4. На Android/iOS тапнуть по зоне шкалы: широкая зона должна активировать scrub.
5. Открыть DJVU: старый кэш должен пересоздаться с `paged-hidpi-v4`; качество должно быть выше.
6. На странице библиотеки проверить новую двухстрочную карточку книги и названия пунктов меню.
