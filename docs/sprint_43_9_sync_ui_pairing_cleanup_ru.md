# Sprint 43.9 — Sync UI cleanup and pairing QR wording

## Цель

Сделать экран синхронизации логичнее после перехода QR-подключения на рабочий backend и убрать лишние пользовательские пояснения.

## Изменения

### QR-код подключения

- Убрана фраза: «В поле ввода будет подставлен только 6-значный код».
- В диалоге QR теперь показывается срок действия кода.
- QR по-прежнему содержит короткий 6-значный код подключения.

### Экран синхронизации

- Блок «Устройство» оставлен для текущего устройства:
  - имя устройства;
  - кнопка редактирования имени;
  - статус подключения.
- Из имени устройства по умолчанию удаляется суффикс `.local`.
- Блок «Статус» расформирован.
- Блок «Подключение устройства» переименован в «Подключение».
- В «Подключении» оставлено только подключение текущего устройства:
  - сканирование QR;
  - ввод цифрового кода приглашения;
  - подключение по коду.
- Добавлен блок «Другое устройство»:
  - показать QR;
  - создать цифровой код подключения;
  - карточка действующего кода.
- В блок «Доверенные устройства» перенесены:
  - аккаунт;
  - редактирование аккаунта;
  - копирование аккаунта;
  - идентификатор устройства;
  - ключ устройства;
  - список доверенных устройств.

## Relay

Relay через SSH обновлять не нужно.

## Regression checklist

- QR-сканер не менялся: используется рабочий backend из Sprint 43.8.
- Подключение по 6-значному коду сохранено.
- Ручной ввод кода сохранён.
- DOCX, EPUB, PDF, DJVU, FB2, TXT, sync protocol, import, Android/iOS platform config и packaging не менялись.
- После сборки обязательно проверить: открытие QR-сканера на Android, генерацию QR, ручной ввод кода и сохранение списка доверенных устройств.
