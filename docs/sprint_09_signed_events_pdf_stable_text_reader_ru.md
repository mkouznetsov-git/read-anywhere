# Sprint 9 — стабильный TXT reader, подпись/replay-защита событий и PDF

## Исправления TXT-reader

Предыдущая реализация использовала виртуализированные блоки текста переменной высоты. На Android это работало быстрее, но на macOS переменная высота элементов могла давать дребезг scrollbar: список уточнял высоты уже после начала прокрутки.

В Sprint 9 TXT-reader переведён на более стандартную схему:

- один `ListView.builder`;
- фиксированная высота строки через `itemExtent`;
- явный `Scrollbar` на всех платформах;
- без вложенных scrollable-виджетов;
- без `PageView` и пагинации;
- locator — первая исходная позиция символа строки, которая находится у верхней границы экрана.

Новый locator:

```json
{
  "type": "txt-line-anchor-v1",
  "anchorChar": 18420,
  "totalChars": 380000,
  "lineIndex": 420,
  "lineCount": 8600,
  "progressPercent": 4.84
}
```

Ожидаемое поведение:

- на Android видна полоса прокрутки;
- нижний progress bar обновляется прямо во время прокрутки;
- на macOS scrollbar не должен прыгать;
- при повторном открытии восстанавливается та же верхняя строка/фрагмент.

## Подпись и replay-защита sync-событий

E2E payload обновлён до версии `readanywhere-e2e-v2`.

Каждое зашифрованное событие теперь содержит:

- `eventId`;
- `issuedAt`;
- `signerDeviceId`;
- AES-GCM ciphertext/MAC;
- `signature` — HMAC-SHA256 поверх envelope-полей и ciphertext.

Replay-защита на клиенте:

- повторный `eventId` отклоняется;
- слишком старые события отклоняются;
- события из будущего отклоняются;
- подпись проверяется перед расшифровкой payload.

Это MVP-уровень защиты на общем ключе аккаунта. Следующий production-шаг — перейти с HMAC на отдельные Ed25519-ключи устройств, чтобы каждое устройство имело собственный публичный ключ в списке доверенных устройств.

## PDF MVP

Добавлена поддержка чтения PDF через пакет `pdfx`:

- открытие локального PDF;
- вертикальная прокрутка страниц;
- отключён page snapping;
- сохранение текущей страницы в locator `pdf-page-v1`;
- синхронизация PDF-прогресса между устройствами.

Locator PDF:

```json
{
  "type": "pdf-page-v1",
  "page": 12,
  "pages": 240,
  "progressPercent": 4.6
}
```

## Проверки

1. Открыть длинный TXT на Mac.
2. Прокручивать колесом и тянуть scrollbar мышью.
3. Проверить, что текст не скачет, а scrollbar не дребезжит.
4. Открыть TXT на Android.
5. Проверить, что виден scrollbar и нижний progress bar меняется во время прокрутки.
6. Закрыть/открыть книгу на том же устройстве — должна вернуться та же верхняя строка.
7. Проверить то же между Mac и Android.
8. Добавить PDF, открыть его, перейти на другую страницу, закрыть/открыть.
9. Проверить синхронизацию страницы PDF между устройствами.
10. Проверить, что старые клиенты лучше обновить одновременно: v2-события совместимы по чтению с v1 только частично.
