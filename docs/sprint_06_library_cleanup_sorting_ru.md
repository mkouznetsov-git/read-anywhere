# Sprint 6 — очистка библиотеки, устройств и стабильная сортировка

## Цели

Sprint 6 закрывает несколько UX/данных-проблем после стабилизации чтения TXT:

- удалить локальный файл книги с текущего устройства, не удаляя книгу из общей библиотеки;
- удалить книгу из библиотеки аккаунта;
- сделать стабильный порядок книг, который не меняется из-за sync-событий и обновления прогресса;
- добавить очистку списка доверенных устройств;
- заложить основу для будущих папок/коллекций.

## Стабильная сортировка библиотеки

Библиотека теперь отображает только активные книги и сортируется детерминированно:

1. название книги по алфавиту;
2. имя файла;
3. дата добавления;
4. `bookId`.

Это временное product-решение для MVP. Оно специально не зависит от `updatedAt` и `progressPercent`, поэтому порядок книг больше не должен прыгать после синхронизации или обновления позиции чтения.

В будущем можно добавить пользовательские варианты сортировки:

- последние открытые;
- по автору;
- по названию;
- по дате добавления;
- по папке/коллекции.

## Удаление книги

В карточке книги добавлено меню действий:

- **Удалить файл с этого устройства** — удаляет локальный файл, но оставляет книгу в библиотеке. Если файл есть на другом устройстве, книгу можно скачать снова.
- **Удалить из библиотеки** — создаёт tombstone-запись. Книга исчезает из списка на всех устройствах после синхронизации.

Для синхронизации удаления добавлено поле `deletedAt` в `BookRecord`. Запись не удаляется физически из `manifest.json` сразу, потому что иначе старый snapshot с другого устройства мог бы вернуть книгу обратно.

## Доверенные устройства

В `TrustedDeviceRecord` добавлено поле `deletedAt`. Устройство теперь можно скрыть из списка доверенных устройств прямо в экране синхронизации.

Ограничения MVP:

- текущее устройство удалить нельзя;
- удалённое устройство можно снова добавить через pairing-код или QR;
- криптографическое принудительное отключение устройства будет отдельным security-спринтом после E2E encryption и подписей событий.

## Проверки

### Стабильный порядок

1. Добавить несколько книг с разными названиями.
2. Пролистать одну книгу, чтобы обновить прогресс.
3. Дождаться sync.
4. Убедиться, что порядок книг не перемешался.

### Удаление локального файла

1. Скачать книгу на Android.
2. В меню книги нажать **Удалить файл с этого устройства**.
3. Книга должна остаться в библиотеке, но стать remote-only.
4. Нажать иконку облака и скачать снова.

### Удаление из библиотеки

1. Удалить книгу из библиотеки на Mac.
2. Дождаться sync.
3. Убедиться, что книга исчезла на Android.
4. Повторно импортировать тот же файл — книга должна вернуться в библиотеку.

### Доверенные устройства

1. Открыть **Синхронизация → Доверенные устройства**.
2. Удалить старое/лишнее устройство.
3. Убедиться, что текущее устройство удалить нельзя.
4. При необходимости подключить удалённое устройство заново через QR-код.
