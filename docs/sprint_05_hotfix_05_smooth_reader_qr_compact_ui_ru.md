# Sprint 5 Hotfix 05 — плавный TXT-reader, QR-pairing и компактная библиотека

## Причина изменений

Предыдущая реализация TXT-reader использовала дискретную пагинацию. На macOS это приводило к трем проблемам:

- прокрутка была не плавной, а постраничной;
- при ресайзе окна приложение заново пересчитывало страницы и заметно подвисало;
- на границах страниц иногда появлялись визуальные обрывы строк.

## Новая модель TXT-reader

TXT-reader снова стал единым плавным вертикальным scroll-view без внутренних scrollable-виджетов и без дискретной пагинации.

Позиция сохраняется не в пикселях и не в номере страницы, а в якоре исходного текста:

```json
{
  "type": "txt-anchor-v1",
  "anchorChar": 18420,
  "totalChars": 380000,
  "chunkIndex": 5,
  "chunkCount": 104,
  "progressPercent": 4.84
}
```

При повторном открытии приложение восстанавливает scroll примерно к тому же месту текста. Точность — до видимого фрагмента/страницы чтения. При ресайзе окна текст просто перелэйаучивается Flutter-ом без пересчёта страниц и без спиннера.

## Компактная библиотека

Карточка книги стала компактнее:

- статус скачивания больше не дублируется фразой «Скачано и проверено»;
- у скачанной книги основная кнопка — иконка чтения;
- у remote-only книги основная кнопка — облако скачивания;
- прогресс чтения отображается тонкой полоской, процент справа от неё.

## QR-pairing

Добавлено:

- кнопка «Создать QR-код» рядом с «Создать код подключения»;
- QR содержит обычную pairing-ссылку `readanywhere://pair?...`;
- на Android/iOS доступна кнопка «Сканировать QR»;
- AndroidManifest получает `android.permission.CAMERA` при генерации платформы.

## Android install artifacts

В Android release artifacts теперь снова добавляется `universal APK`. Он крупнее split-per-ABI APK, зато проще для ручной установки на телефон. Split APK остаются для меньшего размера.

Рекомендация для ручного sideload-тестирования:

1. сначала пробовать `ReadArc-...-android-universal-release.apk`;
2. если нужна минимальная загрузка — использовать `arm64-v8a` на современных телефонах;
3. не устанавливать `.aab` вручную — это формат для Google Play / bundletool.

## Проверки

1. Открыть длинный TXT на macOS.
2. Убедиться, что прокрутка плавная по всей книге.
3. Изменить размер окна — приложение не должно зависать на пересчёте страниц.
4. Пролистать до нужного места, закрыть и открыть книгу снова.
5. Проверить возврат примерно к тому же видимому фрагменту.
6. Создать QR-код на macOS.
7. Отсканировать QR на Android и подключить устройство к аккаунту.
