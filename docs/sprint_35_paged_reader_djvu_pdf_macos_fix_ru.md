# Sprint 35 — постраничный reader, HiDPI DJVU/PDF, macOS bundle signing

## Цели

1. Сделать постраничный режим основным режимом чтения для PDF и DJVU.
2. Убрать громоздкую нижнюю панель `Назад / Вперёд`.
3. Добавить листание жестами влево/вправо.
4. Улучшить качество рендера DJVU на Android по той же логике, что и PDF.
5. Исправить macOS snapshot packaging после добавления embedded `libreadarc_djvu_engine.dylib`.

## Изменения

### PDF

- PDF всегда открывается постранично.
- Листание: горизонтальный свайп влево/вправо.
- При переходе вперёд новая страница открывается сверху.
- При переходе назад предыдущая страница открывается снизу.
- Нижняя панель заменена на компактную строку прогресса.
- Текстовый слой PDF сохранён: переключатель `Текстовый слой / PDF-страницы` и копирование текста остаются в AppBar/FAB.

### DJVU

- DJVU также переведён на постраничный режим.
- Листание: горизонтальный свайп влево/вправо.
- На Android повышен render target до HiDPI-профиля:
  - ширина до 2600 px;
  - высота до 3900 px.
- Добавлен новый render profile `paged-hidpi-v2`, чтобы старые низкокачественные кэши страниц автоматически сбрасывались.
- В native engine добавлена поддержка вывода RGBA/RGB/grayscale pixmap, чтобы часть страниц не отваливалась из-за различий формата буфера.

### Быстрый переход по книге

- Компактная нижняя шкала показывает текущий прогресс и номер страницы.
- Первый тап по шкале активирует режим перехода.
- После активации можно провести по шкале и быстро перейти к нужной странице.
- Тап по области страницы отключает активный режим шкалы.

### macOS packaging

- После копирования `libreadarc_djvu_engine.dylib` в `.app` bundle выполняется ad-hoc codesign для dylib и всего приложения.
- Это должно убрать ошибку Gatekeeper вида `ReadArc.app повреждено`, которая возникла из-за модификации app bundle после Flutter/Xcode build.
- Для публичного релиза всё равно потребуется Developer ID signing + notarization.

## Relay

Relay не менялся. Обновлять сервер через SSH/GitHub Actions не нужно.

1. GitHub Actions: tests + Android/macOS release jobs.

   - открыть PDF и DJVU.
3. Android:
   - установить `arm64-v8a` APK;
   - открыть PDF 34 МБ;
