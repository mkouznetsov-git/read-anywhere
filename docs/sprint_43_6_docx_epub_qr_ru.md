# Sprint 43.6 — DOCX fidelity polish, EPUB navigation cleanup, QR scanner hardening

## Цель

Закрыть оставшиеся регрессии после Sprint 43.5 без изменения relay: улучшить fidelity DOCX, убрать повторяющиеся технические заголовки EPUB, стабилизировать точку перехода по EPUB-ссылкам и сделать экран QR-сканера устойчивее на Android.

## DOCX

- Снижена агрессивность автоматической пагинации: footer-зона больше не отъедает чрезмерно много высоты страницы.
- Пустые страницы, состоящие только из пустых абзацев/page-break артефактов, больше не добавляются в вывод.
- Сохранены пустые строки внутри таблиц и ячеек DOCX.
- Табличный renderer переведён с Flutter `Table` на row/cell layout с первичной поддержкой `gridSpan`; строка `ИТОГО` и подобные объединённые ячейки теперь могут занимать ширину нескольких колонок.
- Табличные alignment/bold/italic продолжают браться из Word XML; эвристическое центрирование коротких ячеек не используется как главный источник истины.
- Табуляции из DOCX сохраняются как широкие пробелы, чтобы служебные строки вроде `М.П.` не прижимались к левому краю.
- Убрана остаточная левая «лесенка» для сгенерированных юридических номеров.

## EPUB

- EPUB parsing теперь работает по содержимому `<body>`, а не по всему HTML-файлу. Это убирает повторение `<title>` книги в начале каждой главы.
- Для обычного текста больше не используются широкие контейнеры `div/section` как render-блоки, потому что они привязывали якоря к слишком ранним местам. Переходы теперь должны попадать ближе к реальной строке заголовка/абзаца.
- После перехода сохраняется фактическая позиция viewport, а не оптимистичный целевой locator.

## QR scanner

- Экран сканера запускает камеру после задержки после route transition, чтобы обойти Android-ошибку инициализации камеры во время attach.
- Возвращён собственный fallback с кнопкой ручного ввода вместо чёрного plugin error screen.
- Обработка lifecycle: камера останавливается при паузе и запускается при возврате.

2. EPUB: открыть книгу Паттона, убедиться, что название книги не вставляется перед каждой главой, проверить переход на `Глава 16. Огранка, полировка, разработка`.
