# Sprint 5 — устойчивое скачивание и восстановление позиции чтения

## Что исправлено в reader

До этого процент чтения сохранялся и синхронизировался, но при повторном открытии TXT-reader часто открывался с начала. Причины:

- экран reader получал `BookRecord`, который мог устареть относительно `manifest.json`;
- позиция пыталась восстановиться до того, как `ListView` успевал посчитать `maxScrollExtent`;
- при быстром закрытии reader последний locator мог не успеть сохраниться из-за debounce.

Теперь reader:

- перед открытием перечитывает свежую запись книги из `manifest.json`;
- восстанавливает позицию по `txt-char-v1` locator после layout;
- делает best-effort flush позиции при закрытии reader;
- продолжает использовать content-based locator, а не pixel scroll offset.

## Как проверить восстановление места чтения

1. Откройте TXT-книгу на Mac.
2. Пролистайте примерно до 30–40%.
3. Подождите 1–2 секунды.
4. Закройте книгу.
5. Откройте эту же книгу снова на Mac.
6. Reader должен открыться около того же фрагмента текста, а не в начале.
7. После sync откройте книгу на Android.
8. Android также должен открыть книгу около того же места.

## Что добавлено в скачивание книг

Sprint 5 усиливает MVP file-transfer:

- timeout, если источник файла не ответил;
- кнопка отмены активного скачивания;
- безопасный retry после ошибки;
- сохранение partial-файла `.part` после сетевой ошибки;
- возобновление скачивания с ближайшей целой границы chunk;
- источник файла умеет начинать отправку с `startChunkIndex`;
- при SHA-256 mismatch partial-файл удаляется.

## Протокол

Download теперь использует расширенный `book_file_accept`:

```json
{
  "type": "book_file_accept",
  "payload": {
    "transferId": "transfer-...",
    "bookId": "...",
    "sourceDeviceId": "...",
    "requestingDeviceId": "...",
    "chunkSize": 262144,
    "startChunkIndex": 12
  }
}
```

Если partial-файл уже есть, клиент выставляет `startChunkIndex` по его размеру. Источник делает seek и отправляет только оставшуюся часть файла.

## Проверка retry/resume

1. Начните скачивание большой книги на Android.
2. Отключите relay или интернет на середине передачи.
3. Скачивание должно перейти в ошибку/паузу, но книга не должна считаться скачанной.
4. Верните подключение.
5. Нажмите скачать снова.
6. Статус должен показать продолжение с уже полученного объёма.
7. После завершения SHA-256 должен совпасть, книга станет локальной.

## Ограничения

Это всё ещё MVP поверх JSON/base64 WebSocket. Для production позже нужны binary frames, backpressure, E2E encryption и отдельные acknowledgements chunks.
