# Sprint 4.2 — подключение устройств по коду

## Цель

Убрать ручное копирование `accountId` из обычного сценария. Пользователь должен подключать новое устройство через короткий pairing-код или через скопированное приглашение.

## Что реализовано

### Relay

Relay обновлён до версии `0.1.3` и получил HTTP endpoints:

```text
POST /pairing/start
POST /pairing/claim
```

Коды хранятся только в памяти процесса relay, действуют до 5 минут и удаляются после первого использования. Relay по-прежнему не хранит книги на диске.

### Клиент

На экране `Синхронизация` добавлен блок `Подключение устройства`.

Первое устройство:

```text
Синхронизация → Подключение устройства → Создать код подключения
```

Новое устройство:

```text
Синхронизация → Подключение устройства → Код или приглашение → Подключиться по коду
```

После успешного подключения новое устройство автоматически получает:

```text
accountId
relay endpoint
owner device id/name
```

и подключается к relay без ручного ввода accountId.

## Приглашение

Кроме 6-значного кода приложение формирует ссылку вида:

```text
readanywhere://pair?relay=https%3A%2F%2Fyour-device.ts.net&code=123456
```

В текущем MVP её можно скопировать и вставить в поле `Код или приглашение`. Позже этот же payload можно будет показывать как QR-код.

## Доверенные устройства

В manifest добавлен список `trustedDevices`. Пока это MVP-список для видимости и диагностики. Production-версия должна заменить это криптографическим trust model:

```text
public key устройства
подпись pairing-запроса
подпись sync-событий
E2E encryption payload
удаление устройства с ротацией ключей
```

## Проверка

1. Запустите local relay или Personal Hub/Tailscale Funnel.
2. На Mac выберите endpoint и нажмите `Проверить relay`.
3. Нажмите `Создать код подключения`.
4. На Android вставьте только код или скопированное приглашение.
5. Нажмите `Подключиться по коду`.
6. Android должен автоматически получить accountId, подключиться и увидеть библиотеку.
7. Добавьте/скачайте книгу и проверьте прогресс чтения.

## Ограничения

- Код не является production-grade безопасностью.
- Код действителен до 5 минут и хранится в RAM relay.
- QR-сканирование ещё не добавлено.
- Удаление доверенного устройства ещё не реализовано.
