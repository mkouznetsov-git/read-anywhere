# Sprint 42A Hotfix 04 — видимый фиксированный DOCX-лист

## Проблема

После Sprint 42A / hotfix 03 приложение запускалось, но при открытии DOCX на macOS и Android отображалась только пустая бежевая область без видимого листа документа.

## Исправление

- DOCX renderer переведён в максимально безопасный режим фиксированной страницы.
- Убрано динамическое масштабирование DOCX-листа при построении дерева виджетов.
- DOCX-лист теперь всегда создаётся с фиксированной логической шириной страницы.
- Если экран уже страницы, включается горизонтальная прокрутка внутри страницы.
- Вертикальная прокрутка основного reader-а сохранена.
- Белый лист должен быть видим даже если документ пустой или содержит только fallback-текст.

Это сознательный стабилизационный шаг: сначала возвращаем гарантированно видимый DOCX-контент, затем продолжаем доводить fit-to-width/zoom без риска снова получить пустой экран.

## Не трогалось

- PDF / DJVU / EPUB / FB2 / TXT.
- EPUB internal links.
- CHM.
- GitHub Actions и версионирование сборок.
- Relay.

## Ручная проверка

1. Запустить ReadArc на macOS.
2. Открыть DOCX.
3. Проверить, что виден белый лист документа и текст/таблицы.
4. Запустить ReadArc на Android.
5. Открыть тот же DOCX.
6. Проверить, что вместо пустой бежевой области виден белый лист; если лист шире экрана, можно двигать его горизонтально.
