# Sprint 16 — EPUB, выделение текста и ускорение передачи

## Что изменено

### EPUB

Добавлена первая поддержка EPUB:

- исходный `.epub` сохраняется как оригинал книги;
- файл EPUB раскрывается локально как ZIP-контейнер;
- порядок чтения берётся из `META-INF/container.xml` и OPF spine;
- XHTML/HTML главы преобразуются в текст;
- прогресс сохраняется через `epub-line-anchor-v1`, как у TXT.

Это MVP-режим чтения EPUB без картинок, CSS и внутренних ссылок. Следующий шаг — rich EPUB reader с оглавлением, изображениями, footnotes и CSS-стилями.

### Копирование текста

Убрано копирование FB2-картинок как data URI — это было неудобно и не нужно для текущего сценария.

Добавлена кнопка копирования видимого фрагмента:

- TXT — копируется несколько строк от текущей верхней строки;
- FB2 — копируется несколько текстовых строк от текущего места;
- EPUB — работает через тот же текстовый reader, что и TXT.

Это промежуточное решение для стабильного многострочного копирования. Нативное выделение мышью/пальцем через виртуализированные списки остаётся отдельной задачей, потому что cross-row selection конфликтует с производительным reader-ом на Android.

### Передача файлов

Размер binary chunk увеличен до 1 MiB, чтобы уменьшить overhead ACK round-trip. Relay теперь принимает binary frames до 4 MiB.

Текущая схема остаётся:

```text
WebSocket binary frame → AES-GCM encrypted chunk → ACK → retry/resume
```

Если скорости около 0.1 MB/s сохранятся на Tailscale/Funnel, следующий системный шаг — прямой LAN/direct transport между устройствами или отдельный локальный HTTP file endpoint на Personal Hub.

## Проверка

1. Импортировать `.epub`.
2. Открыть EPUB, пролистать, закрыть и открыть снова.
3. Проверить sync прогресса EPUB между Mac и Android.
4. Скопировать видимый фрагмент в TXT/FB2/EPUB.
5. Скачать книгу 5–10 MB и сравнить скорость с Sprint 15.
