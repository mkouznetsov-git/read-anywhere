# Sprint 43.5 — DOCX layout polish, EPUB link convergence, QR scanner dependency fix

## DOCX

- Уменьшена визуальная «лесенка» у юридических абзацев: ведущие пробелы/табы из run-ов больше не сдвигают начало строки.
- Номер многоуровневого заголовка наследует жирность заголовка.
- Пагинация стала консервативнее и резервирует отдельную footer-зону, чтобы основной текст не прилипал к нижнему колонтитулу.
- Пустые строки DOCX не выбрасываются и дают больше вертикального интервала.
- Таблицы теперь сохраняют пустые строки и читают alignment/bold/italic из XML ячеек, а не центрируют всё эвристически.

## EPUB

- Переход по внутренней ссылке теперь дополнительно сверяет фактический top-visible locator с целевым progress и итеративно корректирует scroll offset.
- Это закрывает кейсы, где locator показывал правильные 82.6%, но физический viewport оставался около 80.8%.

## QR scanner

- `mobile_scanner` обновлён до `6.0.11`: в changelog этой ветки есть исправления Android camera-null/crash сценариев.
- Код screen оставлен близким к ранней рабочей реализации.
