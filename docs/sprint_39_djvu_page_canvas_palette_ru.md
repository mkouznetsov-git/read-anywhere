# Sprint 39 — DJVU page canvas and ReadArc dark palette

## Цель

Вернуть утверждённую тёмную палитру ReadArc и поправить отображение DJVU так, чтобы страница выглядела как цельный лист с полями и границей, а не как обрезанный/перерастянутый фрагмент.

## Изменения

### Палитра библиотеки

- Карточки книг возвращены к тёмной индиго-палитре.
- Светло-кремовые/золотые карточки убраны.
- Названия книг снова отображаются светлым текстом на тёмном фоне.
- Формат и размер файла сделаны менее броскими: приглушённый мелкий текст.
- Золото оставлено только как акцент: прогресс, кнопки, иконки.

### DJVU page canvas

- Рендер DJVU теперь формирует полный белый page canvas с внутренним полем.
- В UI добавлена тонкая граница страницы и лёгкая тень, чтобы страница воспринималась как лист.
- Отключено агрессивное растягивание изображения через `BoxFit.fill`; используется `BoxFit.contain`.
- Для DJVU добавлен новый cache profile `paged-hidpi-v6-full-canvas-fast`, поэтому старые кэшированные страницы будут пересозданы.
- Размеры HiDPI-рендера сбалансированы: страница остаётся читаемой, но не создаются чрезмерно тяжёлые bitmap-файлы.
- Предзагрузка DJVU расширена: готовятся несколько следующих страниц, чтобы обычное линейное чтение ощущалось быстрее.

### Полоса быстрого перехода

- Визуальная золотая полоса остаётся тонкой.
- Активная индиго-полоса примерно в два раза толще.
- Область попадания пальцем остаётся шире самой полосы, но визуально полоса не раздувается.

## Relay

Relay обновлять не нужно. Серверный код не менялся.

## Проверки в GitHub Actions

- Flutter compile smoke test.
- Flutter unit tests.
- Android release build с `libreadarc_djvu_engine.so`.
- macOS release build с `libreadarc_djvu_engine.dylib`.

## Ручная проверка

1. Открыть библиотеку на macOS/Android и проверить, что карточки снова тёмные, в палитре ReadArc.
2. Проверить, что формат и размер файла не выглядят как яркие чипы.
3. Открыть DJVU на Android:
   - видна граница страницы;
   - есть поля листа;
   - нижний колонтитул и номер страницы не выглядят прижатыми/обрезанными;
   - рендер не должен быть грубо пиксельным.
4. Открыть DJVU на macOS и проверить тот же page-canvas вид.
5. Полистать несколько страниц подряд: после первой страницы следующие должны открываться быстрее за счёт prefetch.
6. Проверить, что полоса быстрого перехода визуально тонкая в обычном режиме и становится толще/индиго только при активации.
