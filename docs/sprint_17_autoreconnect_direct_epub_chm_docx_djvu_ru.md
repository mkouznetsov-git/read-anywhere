# Sprint 17 — reconnect, Direct/LAN transfer, richer EPUB, CHM/DOC/DOCX/DJVU MVP

## Что изменено

### 1. Автопереподключение при старте без relay

Если приложение запускается при выключенном relay/Personal Hub, оно больше не делает одну неудачную попытку и не останавливается. Теперь запускается постоянный reconnect-loop:

- первая попытка сразу;
- затем быстрые повторы;
- после этого — аккуратный интервал без лишнего шума в журнале.

Технические ping/retry-попытки не пишутся в журнал событий.

### 2. Direct/LAN file endpoint

Для ускорения скачивания добавлен прямой локальный endpoint внутри приложения-источника.

Схема:

```text
Android запрашивает книгу через relay
Mac-источник отвечает offer-ом
в offer есть directDownloadUrls: http://LAN-IP:8790/direct-file/<token>
Android сначала пробует Direct/LAN HTTP download
если Direct/LAN не доступен — fallback на encrypted WebSocket relay transfer
```

Особенности:

- исходный файл по-прежнему проверяется по SHA-256;
- поддерживается HTTP Range для resume;
- token живёт ограниченное время;
- direct endpoint слушает порт 8790/8791 или свободный порт;
- если firewall macOS блокирует входящие подключения, приложение автоматически откатится на relay-transfer.

Важно: Direct/LAN режим предназначен для Personal Hub / своей сети / Tailscale-сети. Для полностью внешнего интернета без прямой достижимости будет использоваться relay fallback.

### 3. Многострочное выделение текста

TXT уже использовал общий `SelectionArea`. Для FB2/EPUB rich reader теперь также используется `SelectionArea` вокруг списка текстовых units, а строки рендерятся через обычный `Text.rich`, чтобы Flutter мог выделять несколько строк между видимыми текстовыми элементами.

Кнопка “Скопировать видимый фрагмент” оставлена как стабильный fallback для Android и длинных виртуализированных документов.

### 4. EPUB rich MVP

EPUB теперь открывается через rich reader, а не через простой plain-text reader:

- читается OPF/spine;
- отображаются заголовки;
- отображаются параграфы;
- отображаются встроенные изображения из архива;
- внешние ссылки открываются через браузер;
- позиция сохраняется через `epub-unit-anchor-v1`.

Ограничения MVP:

- CSS EPUB пока не применяется полностью;
- внутренние переходы по якорям пока диагностические;
- сложные таблицы и нестандартные layout-элементы упрощаются до линейного чтения.

### 5. CHM / DOC / DOCX / DJVU

Добавлены маршруты открытия:

- DOCX — извлечение текста из `word/document.xml` внутри zip-контейнера;
- DOC / CHM / DJVU — MVP fallback через извлечение читаемых строк, пока без полноценного нативного рендера;
- оригинальный файл всегда сохраняется и синхронизируется между устройствами.

Production-следующий шаг для этих форматов — подключить локальные конвертеры/нативные адаптеры:

- DOC/DOCX → EPUB/PDF/text layer;
- DJVU → text layer + image/page renderer;
- CHM → HTML sections + resources.

## Что проверить

1. Запустить приложение при выключенном relay.
2. Включить relay через 20–30 секунд.
3. Проверить, что приложение подключилось само.
4. Скачать книгу 5–20 MB на Android и убедиться, что используется Direct/LAN или fallback без зависаний.
5. Проверить скорость скачивания.
6. Открыть EPUB с картинками и ссылками.
7. Проверить выделение текста в TXT/FB2/EPUB.
8. Импортировать DOCX и проверить извлечение текста.
9. Импортировать CHM/DJVU/DOC и проверить MVP fallback.
