# Sprint 42A Hotfix 06 — pairing UI, relay health, library persistence, DOCX visibility

## Цель

Закрыть регрессии и продуктовые замечания после Sprint 42A:

- вернуть гарантированно видимый DOCX-контент вместо пустого бежевого экрана;
- сделать блок подключения устройств логичнее;
- уменьшить ложные статусы «Relay недоступен»;
- сделать публичный `/health` коротким и безопасным;
- снизить риск потери библиотеки при обновлении приложения.

## Изменения в клиенте

### Подключение устройств

- Текст кнопки `Создать короткий код` заменён на `Создать код подключения`.
- Кнопка `Подключиться по коду` перенесена под поле ввода кода/приглашения.
- В поле кода добавлена отправка по Enter.

### Relay connectivity

- WebSocket ready-timeout увеличен с 5 до 12 секунд.
- Health-monitor больше не разрывает websocket после одного неудачного HTTP-проба.
- Отключение и переподключение запускаются только после 3 последовательных health-сбоев.
- На единичных сбоях показывается статус `Подключено. Проверяем relay...`, а не преждевременное `Relay недоступен`.

### Библиотека при обновлении

- Основная папка данных остаётся исторически стабильной: `ReadAnywhere`.
- При пустой основной папке приложение пробует восстановить данные из известных папок `ReadArc` / `ReadAnywhere` в Documents и Application Support.
- Восстановление не удаляет исходные данные и не перезаписывает уже существующие файлы.

### DOCX

- Проблемный DOCX page-wrapper отключён.
- DOCX снова рендерится через простой гарантированно видимый бумажный контейнер.
- Это стабилизационный откат отображения: сначала возвращаем содержимое, затем продолжаем профессиональный page engine без риска пустого экрана.

## Изменения в relay

- `/health` теперь возвращает только:

```text
ok
```

- Диагностическое состояние перенесено в `/debug/state`.
- `/debug/state` доступен только при наличии переменной окружения `READARC_RELAY_DEBUG_TOKEN` и заголовка `X-ReadArc-Debug-Token`.
- Версия relay обновлена до `0.3.2`.

## Relay через SSH

Нужно обновить relay, потому что изменён серверный endpoint `/health`.

После деплоя проверить:

```bash
curl https://relay.readarc.ru/health
```

Ожидаемый ответ:

```text
ok
```

## Ручная проверка

1. Открыть приложение на macOS: библиотека не должна сбрасываться при обновлении поверх предыдущей сборки.
2. Открыть приложение на Android: библиотека должна сохраниться при обновлении поверх предыдущей сборки.
3. Открыть `Договор_поставки.docx`: должен появиться белый лист с содержимым, а не пустой бежевый фон.
4. В блоке `Подключение устройства` проверить новый текст кнопки и порядок элементов.
5. Создать код подключения на одном устройстве и подключить второе устройство по коду.
6. Проверить, что кратковременные network/health сбои не превращаются сразу в `Relay недоступен`.
7. После деплоя relay проверить `curl https://relay.readarc.ru/health`.
