# Sprint 42A Hotfix 09 — pairing UX, download guards, FB2 import, EPUB cleanup, DOCX safe fallback

## Цель

Закрыть текущие UX-замечания по подключению устройств и убрать блокирующие регрессии в импорте/чтении до продолжения большого DOCX-engine трека.

## Изменения

### Подключение устройства

- `Показать QR-код` заменено на `Показать QR`.
- Сгенерированный код подключения теперь отображается как 6 цифр без дефиса.
- В карточке кода оставлены только:
  - сам код;
  - срок действия до секунд;
  - подсказка `Введите код на подключаемом устройстве.`
- Убран текст `Основной сценарий — QR-код...`.
- Поле ручного ввода теперь называется `Введите код приглашения`.
- Убраны подсказки про длинное приглашение и запасной вариант.

### Скачивание

- Если relay не подключён, кнопка скачивания всей библиотеки неактивна.
- Если relay не подключён, кнопки скачивания отдельных книг неактивны.

### Android FB2 import

- На Android file picker переведён на `FileType.any` с последующей внутренней проверкой расширения.
- Это нужно, потому что Android document providers часто не показывают `.fb2` при `FileType.custom` из-за отсутствующего/нестандартного MIME-type.

### DOCX

- Временно отключён проблемный `_DocxReaderScreen` для `.docx`/`.doc`.
- `.docx` и `.doc` возвращены на стабильный rich-reader путь через `_Fb2ReaderScreen`.
- Это аварийный safe fallback: он должен снова показывать содержимое вместо пустого бежевого экрана.
- Профессиональный fixed-page DOCX engine не удалён, но больше не используется как основной экран до отдельной переработки.

### EPUB

- EPUB cover-image из OPF добавляется как изображение, если указана через `properties="cover-image"` или `<meta name="cover" ...>`.
- Навигационные `nav/toc` XHTML-файлы исключаются из основного reading order, чтобы оглавление не шло сплошным текстом в начале книги.
- Внутренние якоря теперь собираются не только с `<a>`, но и с любых вложенных `id/name/xml:id` внутри блока.
- Добавлена поддержка HTML/SVG-тегов `<image ... href=...>` при извлечении изображений из EPUB-глав.
- Если блок обложки содержит только слово `cover`/`обложка` и найдено изображение, текстовый мусор не выводится.

## Relay

Изменений server-side в этом hotfix нет. Если Hotfix 08 с исправлением `/health` и deploy-updater уже был выкачен на сервер, relay обновлять не нужно. Если Hotfix 08 ещё не применялся на сервере, relay всё ещё нужно обновить из-за изменений `/health`.

## Ручная проверка

1. В блоке `Подключение устройства` проверить подписи, порядок элементов и формат кода.
2. Отключить relay и проверить, что скачивание всей библиотеки и отдельных книг недоступно.
3. На Android добавить `.fb2` через системный picker.
4. Открыть `.docx`: вместо пустого бежевого экрана должен появиться читаемый rich-view.
5. Открыть EPUB с обложкой и nav/toc: обложка должна отображаться изображением, оглавление не должно идти сплошным текстом, внутренние ссылки должны попадать ближе к нужным якорям.
