# Sprint 5 hotfix 02 — стабильный page locator для TXT

## Проблема

До этого TXT-reader сохранял прогресс чтения как процент и пытался восстановить место через scroll-position/char-position в ленивом `ListView`.
На разных устройствах и даже при повторном открытии на том же устройстве это давало дрейф: например, книга сохранялась на 5%, но открывалась около 3.8%.

Причина: scroll-offset и оценка высоты ленивого списка зависят от layout, размера окна, шрифта, платформы и от того, какие элементы уже успел измерить Flutter.

## Решение

TXT-reader переведён на content-based logical pages:

```json
{
  "type": "txt-page-v1",
  "pageIndex": 4,
  "pageCount": 100,
  "startChar": 7200,
  "endChar": 9000,
  "totalChars": 180000,
  "progressPercent": 5.0
}
```

Теперь приложение сохраняет не пиксельный scroll-offset, а номер логической страницы.
Открытие книги восстанавливается через `PageView.jumpToPage(pageIndex)`, поэтому результат стабилен на macOS и Android.

## Свойства новой схемы

- точность восстановления: до логической страницы;
- процент чтения считается как `(pageIndex + 1) / pageCount * 100`;
- старые `txt-char-v1` locators мигрируют автоматически при следующем открытии;
- старые `txt-scroll:*` locators игнорируются, fallback идёт через сохранённый процент;
- закладки TXT теперь тоже сохраняются как `txt-page-v1`.

## Ограничение

Логическая страница — это content page примерно по 1800 символов, а не физическая страница экрана. Это сделано намеренно: такая страница одинаково определяется на разных устройствах и не зависит от размера окна.

Для EPUB/PDF позже нужны собственные locators:

- PDF: page number + optional viewport/annotation anchor;
- EPUB: EPUB CFI / spine item + offset;
- FB2/TXT: logical page / char range;
- DOC/DOCX: locator после локальной конвертации.

## Проверка

1. Обновить приложение на Mac и Android.
2. Открыть TXT на Mac.
3. Перейти примерно к 5%.
4. Закрыть книгу.
5. Открыть снова на Mac.
6. Должна открыться та же логическая страница и тот же процент.
7. Дождаться sync.
8. Открыть эту же книгу на Android.
9. Android должен открыть ту же логическую страницу.

Если книга была открыта старой сборкой, нужно один раз открыть её новой сборкой и перелистнуть страницу, чтобы locator обновился до `txt-page-v1`.
