# ADR-005: встроенные движки чтения форматов

## Статус

Принято для Sprint 33.

## Решение

ReadArc не должен требовать от пользователя внешних утилит (`brew install`,
`apt install`, `ddjvu`, `djvused`, `djvutxt`, `extract_chmLib`, `7z`, `unar`) для
чтения книг. Форматные движки должны быть встроены в приложение или поставляться
как часть его пакета.

## DJVU

Не используем GPL DjVuLibre как исходный код внутри ReadArc. Для DJVU выбран
путь `djvu-rs`: MIT-лицензированный pure-Rust decoder, написанный по публичной
спецификации DjVu v3.

Важно: переписывание GPL-кода “своими словами” не снимает GPL-риск. Безопасный
путь — либо использовать совместимую лицензию, либо clean-room реализацию по
спецификации, либо библиотеку с подходящей лицензией.

## PDF

Крупные PDF нельзя открывать через eager-проход по всем страницам. В Sprint 33
добавлен экономный режим для больших PDF: одна страница за раз, ограниченный DPR
и отсутствие синхронного извлечения текста при открытии.

## CHM

CHM должен идти через embedded engine, совместимый с CHMLib/LGPL-2.1-or-later,
с HTML/assets reader pipeline. Старый небезопасный путь не должен запускаться при
открытии CHM.

## Processed artifacts

Processed artifacts остаются архитектурным контрактом, но их создают встроенные
движки ReadArc, а не внешние программы.
