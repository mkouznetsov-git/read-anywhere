# Sprint 25 — официальный relay ReadArc без выбора endpoint

## Что изменено

- Приложение больше не предлагает выбирать режим соединения.
- Удалена пользовательская панель **«Соединение»** со страницы синхронизации.
- Все новые и старые настройки синхронизации мигрируются на официальный relay:

```text
https://relay.readarc.ru
```

- Автоподключение включено всегда.
- QR-код подключения создаётся с официальным relay и больше не требует выбора `Personal Hub / Tailscale Funnel` на новом устройстве.
- Старые QR-ссылки `readanywhere://pair?...` и старые сохранённые настройки всё ещё декодируются, но их custom/Tailscale endpoint игнорируется: клиент подключается через `https://relay.readarc.ru`.
- Docker compose переименован в `readarc`, образ relay — `readarc-relay:dev`, порт relay по умолчанию публикуется только на `127.0.0.1:8787`, чтобы наружу его отдавал nginx.

## Что осталось в UI

На странице **Синхронизация** теперь остаются:

- статус;
- подключение устройства через QR/код;
- раскрываемые доверенные устройства;
- раскрываемый журнал событий;
- раскрываемый блок «Дополнительно» для ручного изменения аккаунта и названия устройства.

## Проверка production relay

```bash
curl https://relay.readarc.ru/health
```

Ожидаемый ответ:

```json
{"ok":true,"rooms":{},"pairing_codes":0}
```
