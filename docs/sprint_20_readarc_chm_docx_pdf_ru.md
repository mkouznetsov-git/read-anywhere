# Sprint 20 — ReadArc: бренд, CHM/DOCX/PDF

## Что изменено

### 1. Бренд ReadArc

- Пользовательское название приложения заменено на **ReadArc**.
- Добавлена новая тёмно-индиговая / золотая / кремовая палитра.
- В библиотеке добавлена компактная бренд-иконка рядом с названием.
- Обновлены ассеты иконки:
  - `assets/app_icon/readarc_icon_1024.png`
  - Android launcher PNG в `assets/app_icon/android/`
  - macOS icon PNG в `assets/app_icon/macos/`
  - Flutter UI asset в `apps/flutter_client/assets/brand/`
- Старый каталог локальных данных `ReadAnywhere` намеренно сохранён, чтобы обновление не потеряло библиотеку пользователя.

### 2. CHM без бинарных “кракозябр”

- CHM теперь не открывается как сырой бинарный текст.
- Добавлен отдельный безопасный CHM text-layer adapter:
  - ищет HTML/TOPIC-фрагменты;
  - извлекает CP1251/UTF-8/UTF-16LE читаемые строки;
  - фильтрует мусорные бинарные участки;
  - если текст безопасно извлечь нельзя, показывает понятное сообщение вместо нечитаемого мусора.

Важно: полноценный CHM renderer всё ещё требует нативный CHM/LZX adapter. Этот sprint убирает “кракозябры” и даёт лучший MVP-preview там, где CHM содержит извлекаемый индекс/HTML-фрагменты.

### 3. DOCX rich MVP

- DOCX теперь рендерится через rich-reader, а не через plain text reader.
- Добавлены визуальные таблицы как отдельные scrollable table blocks.
- Картинки из `word/media/*` извлекаются через relationships.
- Сохраняются базовые элементы документа:
  - заголовки;
  - абзацы;
  - списки;
  - таблицы;
  - изображения;
  - базовые inline-стили: bold / italic / underline.

### 4. PDF

- PDF-reader завёрнут в full-width контейнер на кремовом фоне, чтобы страницы занимали доступную ширину области чтения.
- Добавлен best-effort text layer для текстовых PDF:
  - извлекает текст из обычных и FlateDecode PDF streams;
  - добавляет отдельный selectable режим “Текстовый слой PDF”;
  - добавляет кнопку копирования всего извлечённого текста.
- Для сканов/картинок текстовый режим не показывается, потому что в таких PDF нет настоящего текстового слоя.

## Проверка

В этой среде нет Flutter/Dart SDK, поэтому `flutter analyze` и `flutter test` здесь не запускались. После распаковки архива проверить:

```bash
cd apps/flutter_client
flutter pub get
flutter analyze
flutter test
```

Ручная проверка:

1. Открыть CHM с русским текстом: не должно быть бинарных кракозябр; либо читаемый preview, либо честное сообщение.
2. Открыть DOCX с таблицей и картинкой: таблица должна быть отдельным визуальным блоком, картинка — отображаться как изображение.
3. Открыть текстовый PDF: должна появиться кнопка текстового слоя и копирования.
4. Открыть PDF-скан: кнопка текстового слоя может быть недоступна — это корректно.
5. Проверить, что библиотека после переименования не потерялась: локальный storage directory сохранён совместимым.
